# Strategic-Employee-Attrition-Intelligence-Dashboard 

## Project Overview
This project analyzes employee attrition using a dataset of **5,000 employees**.  
The goal is to find why employees leave and help HR improve retention using an interactive Power BI dashboard.
## Problem
Employee attrition increases cost and reduces productivity.  
Organizations struggle to identify the real reasons behind employees leaving.
## Objectives
- Find overall and department-wise attrition rate
- Identify key factors causing attrition
- Build an interactive Power BI dashboard
- Give useful recommendations to HR
## Dataset
- 5,000 employee records
- 895 employees left (Attrition Rate ≈ 18%)
- Includes department, job role, salary, overtime, burnout, performance, etc.
## Tools Used
- SQL Server
- Power BI
- Power Query
- DAX
## Project Steps
1. Collected employee data (CSV)
2. Loaded data into SQL Server
3. Connected SQL to Power BI and cleaned the data
4. Created KPI cards
5. Built interactive dashboard
6. Created Report 1 and Report 2
7. Analyzed insights and gave recommendations
## Dashboard Features
- KPI Cards (Total Employees, Attrition Rate, etc.)
- Attrition by Department and Job Role
- AI Tool Impact chart
- Decomposition Tree
- Interactive Filters
## Key Insights
- Overall Attrition Rate: **18%**
- Highest attrition in **Customer Support**
- High Burnout and high Overtime increase attrition
- Low performance rating employees leave more
## Conclusion
This dashboard helps HR teams understand attrition reasons and take better decisions to improve employee retention.
